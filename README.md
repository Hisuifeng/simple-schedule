# Simple Schedule

一个零依赖的原生前端课程表，直接用浏览器打开即可使用。

## 功能

- 点击单元格添加、编辑或删除课程（名称、教师、地点、备注、颜色）
- 开启“拖动”后可拖拽移动课程，目标格已有课程时自动互换；再开启“复制”后拖动会复制课程
- 编辑课程时可同步重命名所有同名课程，或一次性删除所有同名课程
- 自定义作息时间：上午开始 / 上午结束 / 下午开始 / 下午结束、每节时长、课间休息
- 按节次添加额外休息，例如“第 10 节前休息 60 分钟”，之后的节次自动顺延
- 隐藏 / 显示任意星期，至少保留一天
- 自动收起没有课程的节次，可在设置中关闭
- 高亮今天所在列；自动高亮当前课程，并在课前 10 分钟高亮即将开始的课程
- 移动端自动定位到今天所在列，横向滚动后编辑课程不会跳回最左
- 课程名过长时流动显示；固定行高、紧凑间距，长备注自动省略
- 按课程名自动配色，同名课程颜色统一
- 数据保存在浏览器 localStorage，支持 JSON 导入 / 导出备份

## 快速开始

1. 下载或克隆本仓库。
2. 直接用浏览器打开 `index.html`。
3. 点击表格单元格开始添加课程。

无需安装依赖，也无需构建。

## 使用说明

- **编辑课程**：点击任意单元格，填写信息后点“保存”。清空全部内容并保存即可删除。
- **移动课程**：打开右上角“拖动”，把课程拖到其他格子；目标格已有课程时互换。
- **复制课程**：打开“拖动”后再打开“复制”，拖动课程会复制到目标格，原课程保留；目标格已有课程时会被覆盖。
- **同名课程**：编辑已有课程时，若存在同名课程，可勾选“保存时同时重命名所有同名课程”，或点“删除所有同名课程”批量删除。
- **设置**：点击右上角“设置”，可调整作息时间、额外休息、星期显示和自动隐藏空行。
- **备份**：在“设置 → 数据备份”中点击“导入 / 导出”，导出 JSON 并复制，或粘贴 JSON 后导入。

## 用大模型导入课程表

可以把课程表截图、PDF、Word 或 Excel 交给支持文件上传的大模型，让它按下面的提示词输出 JSON，再粘贴到“设置 → 数据备份 → 导入 / 导出 → 从文本导入”。

> 导入前建议先导出当前数据备份；导入后请核对节次、周次和教室。本课表一格只能放一门课，且只分上午 / 下午两段。

### 提示词

```text
你是一名课程表数据整理助手。请把我上传的课程表图片或文档转换成下面格式的 JSON。只输出 JSON，不要输出解释，也不要用 Markdown 代码块包裹。

规则：
1. days 按周一到周日排列，只写来源中实际存在的星期，例如 ["周一","周二","周三","周四","周五"]。
2. 课程键为 "day-period"：day 是星期索引，period 是节次索引，均从 0 开始。周一第 1 节 = "0-0"，周三第 5 节 = "2-4"。
3. 一个格子只能放一门课。字段：name 必填，teacher、room、note 没有就填空字符串。
4. 单双周、起止周、合班等信息写入 note。
5. 时间用 24 小时制 HH:MM。
6. 程序会根据 settings 重新生成节次时间，不会使用原表里的具体时间，因此必须保证生成的节次数量不少于来源中的最大节次，否则后面的课程会被丢弃：
   - 45 分钟一节、课间 10 分钟时，08:00–12:00 生成 4 节，14:00–18:00 生成 4 节。
   - 需要 12 节时可用：morningStart 08:00、morningEnd 12:00、afternoonStart 14:00、afternoonEnd 21:30、periodMinutes 45、breakMinutes 10。
   - 晚间课程继续按下午节次编号，用 afternoonEnd 覆盖即可。
7. extraBreaks 表示某节前的额外休息，如 {"10": 60} 表示第 10 节前休息 60 分钟；没有就写 {}。
8. 不要输出 colors、periods、hiddenDays。识别不清的内容在 note 写“待确认”，不要编造。

输出格式：
{
  "days": ["周一", "周二", "周三", "周四", "周五"],
  "settings": {
    "morningStart": "08:00",
    "morningEnd": "12:00",
    "afternoonStart": "14:00",
    "afternoonEnd": "18:00",
    "periodMinutes": 45,
    "breakMinutes": 10,
    "extraBreaks": {},
    "hideEmptyPeriods": true
  },
  "courses": {
    "0-0": { "name": "高等数学", "teacher": "张老师", "room": "A101", "note": "" },
    "2-4": { "name": "大学英语", "teacher": "李老师", "room": "B202", "note": "1-16周" }
  }
}
```

### 校验提示词

如果模型返回的课程数量不对，可以继续追问：

```text
请检查上面的 JSON：1. 每门课的 day 是否在 days 范围内；2. period 是否小于 settings 生成的节次总数；3. 是否遗漏单双周或起止周信息。修正后只输出 JSON。
```

## 数据说明

课程数据只保存在当前浏览器的 localStorage 中，不会上传到服务器。清除浏览器数据前请先导出备份。
