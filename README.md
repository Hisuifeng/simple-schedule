# Simple Schedule

一个零依赖的原生前端课程表，直接用浏览器打开即可使用。

## 功能

- 点击单元格添加、编辑或删除课程（名称、教师、地点、备注、颜色）
- 开启“拖动调整”后可拖拽移动课程，目标格已有课程时自动互换
- 自定义作息时间：上午开始 / 上午结束 / 下午开始 / 下午结束、每节时长、课间休息
- 按节次添加额外休息，例如“第 10 节前休息 60 分钟”，之后的节次自动顺延
- 隐藏 / 显示任意星期，至少保留一天
- 按课程名自动配色，同名课程颜色统一
- 数据保存在浏览器 localStorage，支持 JSON 导入 / 导出备份

## 快速开始

1. 下载或克隆本仓库。
2. 直接用浏览器打开 `index.html`。
3. 点击表格单元格开始添加课程。

无需安装依赖，也无需构建。

## 使用说明

- **编辑课程**：点击任意单元格，填写信息后点“保存”。清空全部内容并保存即可删除。
- **移动课程**：打开右上角“拖动调整”，把课程拖到其他格子。
- **设置**：点击右上角“设置”，可调整作息时间、额外休息和星期显示。
- **备份**：点击“导入 / 导出”，导出 JSON 并复制，或粘贴 JSON 后导入。

## 文件结构

```text
index.html   页面结构
styles.css   样式（含移动端适配）
app.js       全部交互逻辑
```

## 数据说明

课程数据只保存在当前浏览器的 localStorage 中，不会上传到服务器。清除浏览器数据前请先导出备份。
